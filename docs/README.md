# MAHAR | مهار
### بازی تعاملی کشف توانایی‌ها و مسیرهای مهارتی

**MAHAR** یک پلتفرم تعاملی برای خودشناسی و کشف مسیرهای مهارتی است که به نوجوانان و بزرگسالان کمک می‌کند علایق، شیوه حل مسئله و توانایی‌های خود را بهتر بشناسند و برای شروع یادگیری یک مهارت مناسب تصمیم آگاهانه‌تری بگیرند.

مهار با استفاده از یک بازی داستانی چهارمرحله‌ای، کاربر را وارد موقعیت‌های مختلف می‌کند تا به‌جای پاسخ دادن به پرسش‌نامه‌های معمول، از طریق انتخاب‌ها، تصمیم‌ها و فعالیت‌های عملی، اطلاعاتی درباره علایق و عملکرد خود به دست آورد.

در پایان، سیستم یک گزارش خودشناسی شامل تحلیل علایق، نقاط قوت احتمالی و سه مسیر مهارتی پیشنهادی ارائه می‌دهد.

---

## 🎯 اهداف پروژه

- کمک به افرادی که برای انتخاب مسیر شغلی یا مهارتی سردرگم هستند.
- شناسایی علایق و ترجیحات فعالیتی از طریق تجربه تعاملی.
- بررسی تفاوت بین علاقه و عملکرد واقعی در فعالیت‌ها.
- ارائه پیشنهادهای مهارتی بر اساس رفتار و انتخاب‌های کاربر.
- ایجاد نقطه شروعی برای یادگیری مهارت‌های جدید.

## 🎮 ساختار بازی

بازی مهار از چهار مرحله اصلی تشکیل شده است و هر مرحله بخشی از اطلاعات موردنیاز برای تهیه گزارش نهایی را جمع‌آوری می‌کند.

### مرحله اول: جزیره انتخاب‌ها
کاربر در یک جزیره با شش محیط مختلف روبه‌رو می‌شود و با بررسی فعالیت‌های هر محیط، علایق خود را مشخص می‌کند.

**هدف:** بررسی علایق فعالیتی بر اساس مدل هالند (RIASEC).

### مرحله دوم: مأموریت نجات شهر هوشمند نورآباد
کاربر باید در شرایط بحرانی، تصمیم‌های مختلفی بگیرد، سرنخ‌ها را بررسی کند و ابزارهای موردنیاز را انتخاب کند.

**هدف:** بررسی شیوه حل مسئله، تصمیم‌گیری، ریسک‌پذیری و نحوه مواجهه با چالش‌ها.

### مرحله سوم: کارگاه خلاقیت
کاربر وارد یک کارگاه تعاملی می‌شود و با چهار فعالیت مختلف روبه‌رو خواهد شد:

- الگوی گمشده: حل معما و شناسایی الگوها
- سازمان‌دهی انبار: دسته‌بندی و مرتب‌سازی ابزارها
- طراحی غرفه: طراحی آزاد و ارائه ایده
- تعمیر مدار: فعالیت اختیاری برای بررسی توانایی فضایی و فنی

**هدف:** بررسی عملکرد مشاهده‌شده، دقت، استدلال، خلاقیت و یادگیری از بازخورد.

### مرحله چهارم: سرزمین آینده
کاربر از میان شش دنیای شغلی، سه مورد را به ترتیب علاقه انتخاب می‌کند و جواهرهای خود را بین سه نیاز انگیزشی تقسیم می‌کند.

**هدف:** تکمیل اطلاعات علایق شغلی و بررسی انگیزه‌های فردی.

## 🧠 منطق ارزیابی و تحلیل

یکی از ویژگی‌های اصلی مهار، تفکیک علاقه از عملکرد است.

سیستم صرفاً بر اساس انتخاب‌های کاربر درباره توانایی‌های او نتیجه‌گیری نمی‌کند؛ بلکه اطلاعات مراحل مختلف را با یکدیگر ترکیب می‌کند.

### مبانی مورد استفاده

- مدل رغبت‌سنجی شغلی هالند (RIASEC)
- نظریه خودتعیین‌گری (Self-Determination Theory)
- مفاهیم حل مسئله و تصمیم‌گیری
- شاخص‌های عملکرد مشاهده‌شده در فعالیت‌های عملی

### نحوه محاسبه

امتیاز علایق از ترکیب اطلاعات مرحله اول و چهارم به دست می‌آید.

امتیاز عملکرد بر اساس نتایج فعالیت‌های عملی مرحله سوم محاسبه می‌شود.

امتیاز بازی و نشان‌های دریافتی صرفاً جنبه انگیزشی دارند و در محاسبه ارزیابی نهایی استفاده نمی‌شوند.

### پیشنهاد مسیرهای مهارتی

سیستم از یک کاتالوگ شامل ۱۵ مسیر مهارتی استفاده می‌کند.

مسیرهای پیشنهادی بر اساس ترکیب سه مؤلفه رتبه‌بندی می‌شوند:

| مؤلفه | وزن |
|---|---:|
| تطابق علایق | ۵۵٪ |
| تطابق رویکرد | ۲۵٪ |
| تناسب عملکرد | ۲۰٪ |

در نهایت سه مسیر پیشنهادی همراه با دلایل انتخاب و یک پروژه کوچک برای شروع به کاربر نمایش داده می‌شود.

> نکته: مهار یک ابزار خودشناسی و جهت‌یابی مهارتی است و ادعای تشخیص قطعی استعداد، هوش یا شخصیت ندارد.

پس از تکمیل بازی، گزارشی شامل موارد زیر تولید می‌شود:

- نمودار علایق بر اساس مدل RIASEC
- نقاط قوت احتمالی همراه با شواهد رفتاری

هدف گزارش، ارائه یک نقطه شروع عملی برای شناخت بهتر خود و انتخاب مسیر یادگیری است.

## 🚀 اجرای پروژه

برای اجرای پروژه در محیط توسعه:

### ۱. دریافت پروژه

```bash
git clone YOUR_REPOSITORY_URL
cd mahar
```

### ۲. راه‌اندازی بک‌اند

```bash
python -m venv venv
```

فعال‌سازی محیط مجازی در ویندوز:

```bash
venv\Scripts\activate
```

نصب وابستگی‌ها:

```bash
pip install -r requirements.txt
```

اجرای بک‌اند:

```bash
python app.py
```

### ۳. اجرای فرانت‌اند

در ترمینال دیگری وارد پوشه فرانت‌اند شوید و دستور اجرای متناسب با تنظیمات پروژه را اجرا کنید.

```bash
npm install
npm run dev
```

> مسیرها و دستورات اجرای پروژه را پیش از انتشار با ساختار واقعی مخزن و فایل‌های تنظیمات آن تطبیق دهید.
